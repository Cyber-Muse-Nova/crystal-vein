# 人格障碍自测 · 晶脉 Crystal Vein

十种人格障碍，加上自闭症谱系和 ADHD 特质的自评问卷。每一道题对应一条 DSM-5 诊断标准，结果以一块十二面的水晶呈现。

在线访问：https://cyber-muse-nova.github.io/crystal-vein/

两种版本：完整版 118 题，逐条对照 DSM-5 标准；简化版 45 题，每种模式只问最核心的几条。

覆盖：偏执型、分裂样、分裂型、反社会型、边缘型、表演型、自恋型、回避型、依赖型、强迫型人格，以及自闭症谱系特质和 ADHD 特质。

> 题目依据 DSM-5 标准原创编写，仅供自我观察，不是心理诊断。所有答案只保存在浏览器本地。
